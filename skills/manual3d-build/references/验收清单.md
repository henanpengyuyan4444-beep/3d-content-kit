# 交付验收清单

逐项打勾，任何一项红都不交付。

## A. 数据（脚本可判）

- [ ] `python scripts/check_sku.py sku.json` 五条全过：G1 零件完整、G2 竖板数对、G3 层板整块、G4 引用闭合、G5 页映射对
- [ ] 单位是毫米；整机尺寸与手册标注一致（误差 ±5mm 内）
- [ ] 相接的面贴合：抽 3 对相邻板，内表面坐标相等
- [ ] 每块板至少在某一步 `add` 里出现过，没有"装了但没人提起"的板

## B. 工程（命令可判）

- [ ] `npx tsc --noEmit` 通过
- [ ] `npm run lint` 0 error（warning 可留）
- [ ] `npm run dev` 能打开，控制台无报错
- [ ] 页图路径全部可访问，没有 404

## C. 观感（人眼判）

- [ ] 手机 390×844 竖屏：步骤文字不盖住 3D，按钮单手能够到
- [ ] 每一步零件飞入方向合理：不从柜体里穿出来、不落到画面外
- [ ] 五金数量与手册一致（抽查 2 步）
- [ ] 原页对照点开是这一步的页面，不是上一页
- [ ] 最后一步装完的形态与手册成品图一致（比例、层数、开门方向）

## D. 交付包（五样）

- [ ] 链接（或压缩包 + 启动说明）
- [ ] 步骤清单（第几步做什么，一页纸）
- [ ] 改稿规则写清：含 1 次文案修改，改结构算新单
- [ ] 边界声明：尺寸是推算的，不做开料；孔位是示意
- [ ] 原页对照的使用说明（告诉客户这是给终端用户核对的）

## 给客户的话术

**报价时**：

> 你发我说明书，我按页数和步数报。10 到 15 步大概 800 到 1200，含一次文案修改；超过 25 步要拆或者加价。

**交付时**：

> 这个是链接，手机直接打开。每一步左边是 3D，右边是这一步要用什么，左下角可以点开原说明书那一页对照。尺寸是按你手册推算的，做安装指导够用，但不能拿来开料。

**被问到"能不能自动生成"时**：

> 结构是人定的，AI 只帮我排版和检查。自动读图现在会把多视角画法当成多块板，我不敢拿这个给你交货。

**被砍价时**：

> 这个价里有一半是核对尺寸和步骤顺序的时间。你可以先做一款试试，觉得值再做后面的。
