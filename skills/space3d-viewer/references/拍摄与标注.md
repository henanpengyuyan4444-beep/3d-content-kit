# 拍摄与标注

## 一、拍全景（客户自己就能拍）

1. **选机位**：站在店里最想让人看到的位置，比如进门后两步、吧台前。
2. **高度**：手机举到约 1.5 米（大概眼睛高度），不要举太高，否则地面被压缩。
3. **用系统相机**：iPhone「全景」、安卓「全景/球形全景」都行；不要用第三方拼接 App。
4. **姿势**：双脚不动，身体带着手机水平转一圈；手机保持竖直，别上下点头。
5. **方向**：从最亮的地方开始转（比如门口），接缝会落在暗处，看不出来。
6. **光线**：白天自然光最好；晚上开满灯，别让灯直射镜头。
7. **检查**：拍完在手机上看一圈，出现接缝错位、地面断裂、人脸拉伸，就重拍。

导出：原图（不要微信压缩）。宽度 4096 够用，超过 8192 没有意义，只会让页面变重。

## 二、标热点

热点用两个角度定位：

- `yaw`：水平方向，0 是页面打开时正对的方向，正数向右转，单位度。
- `pitch`：垂直方向，0 是水平，负数往下看，正数往上看，范围 -85 到 85。

**校准顺序**（第一次做一款必走）：

1. 打开页面，找到你想标注的物体（比如吧台）。
2. 拖动让人正对物体，记住当前朝向：从左往右拖是负、从右往左拖是正。
3. 把 `yaw` 调到 -180 到 180 之间，刷新，看点是否落在物体上。
4. 上下差一点就调 `pitch`，一般 -20 到 0 之间。
5. 六个点以内手工试就能准；超过十个点建议先标 3 个定位点再批量推。

## 三、热点内容怎么写

| 字段 | 用途 | 示例 |
| --- | --- | --- |
| label | 页面上显示的短标签 | 吧台、靠窗卡座、2 号货架 |
| desc | 点开后的一两句话 | 点单与出品区，二层是座位 |
| price | 价格 / 人均 / 低消 | 人均 ¥38、低消 ¥45/位 |

写法建议：label 不超过 6 个字；desc 说"是什么、有什么"；price 只放一个数字概念，别写活动规则。

## 四、一个店拍几个机位

- 小店：1 个机位够（站在中间）。
- 有分区：2 到 3 个（门口、吧台、座位区），后面做机位切换。
- 多楼层：每层 1 到 2 个，楼梯口一个。

## 五、常见问题

- **画面很晕**：机位在走道正中，人走动时看会晃；换到靠墙的位置。
- **接缝明显**：拍摄时上下晃了，或转太快；重拍，慢一点。
- **太暗**：店里灯不够；开灯或换白天拍。
- **加载慢**：图太大；压到 4096 宽、1MB 以内。
